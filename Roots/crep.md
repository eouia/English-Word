# crep

- 출발 단어: `discrepancy`
- 핵심 어원: Latin `crepare` = rattle, crack, sound
- 핵심 이미지: 소리가 서로 맞지 않음에서 차이와 불일치로 확장
- 관련 문서: [[dict]]

## 출발 단어 분석

`discrepancy`는 Latin `discrepare` 계열.

- `dis-`: apart
- `crepare`: sound, crack, rattle

원래 이미지는 "서로 다르게 소리 남"이고, 현대 의미는 "수치·진술·사실 사이의 불일치".

## 단어들

### discrepancy

- 발음: /dɪˈskrɛpənsi/
- 구성: `dis-` = apart + `crep`
- 뜻: 불일치, 차이, 모순
- 어원적 연결: 서로 다른 소리를 내듯 사실이나 수치가 맞지 않음
- 사용 맥락: `a discrepancy between the two reports` = 두 보고서 사이의 불일치

### discrepant

- 발음: /dɪˈskrɛpənt/
- 구성: Latin `discrepans` = sounding differently, differing
- 뜻: 서로 맞지 않는, 불일치하는
- 어원적 연결: 서로 다른 방향의 소리처럼 일치하지 않음
- 사용 맥락: `discrepant results` = 서로 맞지 않는 결과

### crepitate

- 발음: /ˈkrɛpəˌteɪt/
- 구성: Latin `crepitare` = crackle
- 뜻: 딱딱 소리를 내다
- 어원적 연결: `crep`의 원래 소리 이미지가 남은 단어
- 사용 맥락: 드문 전문어. 시험 어휘에서는 `discrepancy` 중심으로 기억.

## 기억 포인트

`crep` 계열은 "소리가 맞지 않음"에서 "불일치"로 확장.

- `discrepancy`: 보고·수치·진술 사이의 불일치
- `discrepant`: 서로 맞지 않는

## 비교 단어

### discord

- 뜻: 불화, 불일치
- 구분 포인트: [[cord]] 계열은 "마음, 조화"가 어긋남. `discrepancy`는 사실·수치·진술의 차이에 자주 쓰임.
