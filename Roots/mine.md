# mine

- 출발 단어: `undermine`
- 핵심 어원: Old French `miner` = dig a mine
- 핵심 이미지: 아래를 파서 기반을 약하게 만듦
- 관련 문서: [[minere]]

## 출발 단어 분석

`undermine`은 `under` + `mine`.

- `under`: 아래
- `mine`: 땅을 파다, 갱도를 파다

원래는 성벽이나 구조물 아래를 파서 무너뜨리는 뜻이고, 현대 영어에서는 권위·신뢰·주장을 약화시키는 뜻으로 자주 쓰임.

## 단어들

### undermine

- 발음: /ˌʌndɚˈmaɪn/
- 구성: `under` + `mine`
- 뜻: 약화시키다, 서서히 해치다
- 어원적 연결: 밑을 파서 기반을 무너뜨림
- 사용 맥락: `undermine confidence` = 신뢰를 약화시키다

### mine

- 발음: /maɪn/
- 구성: Old French `mine` / `miner`
- 뜻: 광산; 채굴하다
- 어원적 연결: 땅속을 파서 자원을 얻거나 통로를 냄
- 사용 맥락: `mine coal` = 석탄을 채굴하다

### miner

- 발음: /ˈmaɪnɚ/
- 구성: `mine` + `-er`
- 뜻: 광부
- 어원적 연결: 땅을 파고 채굴하는 사람
- 사용 맥락: `coal miners` = 탄광 노동자들

### mineral

- 발음: /ˈmɪnɚəl/
- 구성: Medieval Latin `minerale` = something mined
- 뜻: 광물
- 어원적 연결: 광산에서 캐내는 물질
- 사용 맥락: `mineral resources` = 광물 자원

## 기억 포인트

`mine` 계열은 "땅속을 팜" 이미지.

- `mine`: 광산, 채굴하다
- `miner`: 채굴하는 사람
- `mineral`: 캐낼 수 있는 광물
- `undermine`: 아래를 파서 기반을 약하게 함

## 비교 단어

### minere

- 뜻: 튀어나오다, 드리워지다
- 구분 포인트: [[minere]]의 `imminent`, `prominent`와 철자가 비슷하지만 다른 어원. `undermine`은 "파다"의 `mine`.
