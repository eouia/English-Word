# erg

- 출발 단어: `energy`
- 핵심 어원: Greek `ergon` = work, action
- 핵심 이미지: 일이 실제로 작동하고 힘을 내는 상태
- 관련 어근: [[em]], [[sym]], [[oper]]

## 출발 단어 분석

`energy`는 Greek `energeia`에서 온 말.

`energeia`는 `en-` = in + `ergon` = work, action의 결합. 원래는 "작동 중인 상태, 활동성"에 가까운 말.

따라서 `energy`는 "안에서 실제로 작동하는 힘" → "에너지, 활력, 활동력"의 뜻.

## 단어들

### energy

- 발음: /ˈɛnɚdʒi/
- 구성: Greek `en-` = in + `ergon` = work, action
- 의미: 에너지, 활력, 활동력
- 어원적 연결: 안에서 작동하는 힘이나 활동성
- 사용 맥락: `renewable energy` = 재생에너지, `creative energy` = 창조적 활력

### energetic

- 발음: /ˌɛnɚˈdʒɛtɪk/
- 구성: `energy` + `-etic`
- 의미: 활기찬, 정력적인
- 어원적 연결: 에너지 있게 움직이거나 작동함
- 사용 맥락: `an energetic speaker` = 활기찬 연설자

### energize

- 발음: /ˈɛnɚˌdʒaɪz/
- 구성: `energy` + `-ize`
- 의미: 활력을 주다, 에너지를 공급하다
- 어원적 연결: 어떤 사람이나 체계가 작동할 힘을 갖게 함
- 사용 맥락: `energize the team` = 팀에 활력을 불어넣다

### synergy

- 발음: /ˈsɪnɚdʒi/
- 구성: `syn-` = together + `ergon` = work
- 의미: 시너지, 상승효과
- 어원적 연결: 여러 요소가 함께 작동해 더 큰 효과를 냄
- 사용 맥락: `team synergy` = 팀 시너지
- 참고: `syn-` 관점에서는 [[sym#synergy|sym]] 문서에서도 볼 수 있음.

### ergonomic

- 발음: /ˌɝɡəˈnɑmɪk/
- 구성: `ergon` = work + Greek `nomos` = law, management
- 의미: 인체공학적인, 작업 효율과 몸의 부담을 고려한
- 어원적 연결: 사람이 일하는 방식과 조건을 체계적으로 맞춤
- 사용 맥락: `an ergonomic chair` = 인체공학적 의자

### ergonomics

- 발음: /ˌɝɡəˈnɑmɪks/
- 구성: `ergonomic` + `-s`
- 의미: 인체공학
- 어원적 연결: 작업 환경을 사람의 몸과 효율에 맞게 연구하는 분야
- 사용 맥락: `workplace ergonomics` = 작업장 인체공학

### allergy

- 발음: /ˈælɚdʒi/
- 구성: Greek `allos` = other + `ergon` = work, reaction
- 의미: 알레르기
- 어원적 연결: 몸이 평소와 다른 방식으로 반응함
- 사용 맥락: `a peanut allergy` = 땅콩 알레르기
- 주의: 현대 영어에서 `allergy`를 `erg` 계열로 직접 분해해 외우기보다는, 의학적 조어에서 `other reaction` 이미지가 들어간 말로 이해하면 충분함.

### allergic

- 발음: /əˈlɝdʒɪk/
- 구성: `allergy` + `-ic`
- 의미: 알레르기가 있는, 알레르기성의
- 어원적 연결: 특정 자극에 대해 다른 반응을 보임
- 사용 맥락: `be allergic to pollen` = 꽃가루 알레르기가 있다

### surgery

- 발음: /ˈsɝdʒəri/
- 구성: Greek `cheir` = hand + `ergon` = work
- 의미: 외과 수술
- 어원적 연결: 손으로 하는 치료 작업
- 사용 맥락: `undergo surgery` = 수술을 받다

### metallurgy

- 발음: /ˈmɛtəlɝdʒi/
- 구성: Greek `metallon` = metal + `ergon` = work
- 의미: 야금학, 금속 공학
- 어원적 연결: 금속을 다루고 가공하는 작업
- 사용 맥락: `advances in metallurgy` = 야금학의 발전

## 비교 단어

- `enervate`: `energy`와 뜻은 비슷해 보이지만 Latin `nervus` = nerve 계열. "기운을 빼다"라는 뜻.
- `work`: 의미상 대응되는 기본어지만 Germanic 계열. `ergon`과 직접 같은 어원은 아님.
