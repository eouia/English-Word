# vad

- 출발 단어: `pervasive`
- 핵심 어원: Latin `vadere` / `vas-` = go
- 핵심 이미지: 어떤 곳을 지나가거나 뚫고 들어감
- 관련 문서: [[via]], [[gress]]

## 출발 단어 분석

`pervasive`는 Latin `pervadere`에서 온 `pervade`의 형용사형.

- `per-`: through
- `vadere`: go

따라서 `pervasive`는 "두루 지나가 퍼지는" → "널리 스며든, 만연한"의 뜻.

## 단어들

### pervasive

- 발음: /pɚˈveɪsɪv/
- 구성: `per-` = through + `vas/vad`
- 뜻: 널리 퍼진, 만연한
- 어원적 연결: 어떤 현상이나 분위기가 곳곳을 지나가며 스며듦
- 사용 맥락: `pervasive influence` = 광범위한 영향

### pervade

- 발음: /pɚˈveɪd/
- 구성: Latin `pervadere` = go through
- 뜻: 스며들다, 퍼지다
- 어원적 연결: 전체를 뚫고 지나가며 퍼짐
- 사용 맥락: `a smell pervades the room` = 냄새가 방 안에 퍼지다

### invade

- 발음: /ɪnˈveɪd/
- 구성: `in-` = into + `vadere`
- 뜻: 침입하다, 침범하다
- 어원적 연결: 안으로 들어가 침범함
- 사용 맥락: `invade privacy` = 사생활을 침해하다

### invasion

- 발음: /ɪnˈveɪʒən/
- 구성: `invade` + `-ion`
- 뜻: 침입, 침략, 침해
- 어원적 연결: 안으로 들어가 경계를 침범하는 행위
- 사용 맥락: `an invasion of privacy` = 사생활 침해

### evade

- 발음: /ɪˈveɪd/
- 구성: `ex-` = out + `vadere`
- 뜻: 피하다, 회피하다
- 어원적 연결: 밖으로 빠져나가 피함
- 사용 맥락: `evade responsibility` = 책임을 회피하다

### evasive

- 발음: /ɪˈveɪsɪv/
- 구성: `evade` + `-ive`
- 뜻: 회피하는, 얼버무리는
- 어원적 연결: 직접 답하지 않고 빠져나감
- 사용 맥락: `an evasive answer` = 회피적인 답변

## 기억 포인트

`vad/vas` 계열은 "가다, 지나가다" 이미지.

- `pervasive`: 두루 지나가 퍼짐
- `pervade`: 전체에 스며듦
- `invade`: 안으로 들어가 침범함
- `evade`: 밖으로 빠져나가 피함

## 비교 단어

### via

- 뜻: 길, 길을 통해
- 구분 포인트: [[via]]는 길 자체의 이미지. `vad`는 어떤 방향으로 움직여 들어가거나 빠져나가는 동작에 초점.
