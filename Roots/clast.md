# clast

- 출발 단어: `iconoclastic`
- 핵심 어원: Greek `klastos` = broken, `klan` = break
- 핵심 이미지: 단단히 세워진 것을 깨뜨림
- 관련 어근: [[fract]], [[rupt]]
- 주의: `iconoclastic`의 `icon`은 Greek `eikon` = image, likeness 계열. `clast`는 "깨뜨리는 사람/것" 쪽 의미를 담당함.

## 출발 단어 분석

`iconoclastic`은 `iconoclast` + `-ic`.

`iconoclast`는 Greek `eikon` = image, icon + `klastes` = breaker의 결합. 원래는 종교적 성상이나 이미지를 부수는 사람을 뜻함.

현대 영어에서는 실제 성상 파괴자보다, 사회적 권위·전통·통념을 깨뜨리는 사람이나 태도를 가리키는 말로 자주 씀.

따라서 `iconoclastic`은 "우상·상징을 깨뜨리는" → "전통 파괴적인, 관습에 도전하는"의 뜻.

## 단어들

### iconoclast

- 발음: /aɪˈkɑnəˌklæst/
- 구성: Greek `eikon` = image + `klastes` = breaker
- 뜻: 우상 파괴자, 전통·권위에 도전하는 사람
- 어원적 연결: 사람들이 숭배하거나 당연하게 여기는 이미지를 깨뜨리는 사람
- 사용 맥락: `a political iconoclast` = 정치적 통념을 깨는 인물

### iconoclastic

- 발음: /aɪˌkɑnəˈklæstɪk/
- 구성: `iconoclast` + `-ic`
- 뜻: 우상 파괴적인, 전통·관습에 도전하는
- 어원적 연결: 상징적 권위나 고정관념을 깨뜨리는 성질
- 사용 맥락: `an iconoclastic thinker` = 관습을 깨는 사상가

### iconoclasm

- 발음: /aɪˈkɑnəˌklæzəm/
- 구성: `iconoclast` + `-ism`
- 뜻: 우상 파괴, 전통·권위 비판
- 어원적 연결: 숭배되는 이미지나 제도적 권위를 깨뜨리는 태도
- 사용 맥락: `religious iconoclasm` = 종교적 성상 파괴

### clastic

- 발음: /ˈklæstɪk/
- 구성: Greek `klastos` = broken
- 뜻: 쇄설성의, 부서진 조각으로 된
- 어원적 연결: 암석이나 물질이 깨진 조각들로 이루어짐
- 사용 맥락: `clastic sedimentary rock` = 쇄설성 퇴적암

### pyroclastic

- 발음: /ˌpaɪroʊˈklæstɪk/
- 구성: Greek `pyr` = fire + `clastic` = broken
- 뜻: 화산 쇄설성의
- 어원적 연결: 화산 폭발로 깨져 나온 뜨거운 파편
- 사용 맥락: `pyroclastic flow` = 화쇄류

### osteoclast

- 발음: /ˈɑstiəˌklæst/
- 구성: Greek `osteon` = bone + `klastes` = breaker
- 뜻: 파골세포
- 어원적 연결: 뼈 조직을 분해하고 흡수하는 세포
- 사용 맥락: 생물·의학 문맥. 일반 시험 어휘보다는 `iconoclast`, `pyroclastic` 이해 보조용.

## 기억 포인트

`clast`는 "깨뜨림, 깨진 조각" 이미지.

- `iconoclast`: 이미지를 깨뜨리는 사람 → 권위·통념 파괴자
- `iconoclastic`: 전통·관습에 도전하는
- `clastic`: 깨진 조각으로 된
- `pyroclastic`: 화산 폭발로 깨진 파편의

## 비교 단어

### fract

- 뜻: 깨다, 부수다
- 구분 포인트: [[fract]]는 Latin `frangere` 계열. `fragment`, `fracture`, `fraction`처럼 깨져 나뉜 조각이나 균열에 넓게 씀.

### rupt

- 뜻: 터뜨리다, 끊다
- 구분 포인트: [[rupt]]는 흐름이나 질서가 터져 끊기는 느낌. `clast`는 더 직접적인 "깨뜨리는 사람/조각" 이미지.

### icon

- 뜻: 이미지, 상징
- 구분 포인트: `iconoclastic`에서 `icon`은 깨지는 대상. 핵심 동작은 `clast` = break 쪽.
