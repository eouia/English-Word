# van

- 출발 단어: `vanish`
- 핵심 어원: Latin `vanus` = empty, vain, void
- 핵심 이미지: 비어 있어 헛되거나 흔적 없이 사라짐
- 관련 어근: [[void]], [[vapor]]
- 주의: `vanquish`는 철자가 비슷하지만 Latin `vincere` = conquer 계열. [[vict]] 문서의 단어.

## 출발 단어 분석

`vanish`는 Old French `esvanir`를 거쳐 들어온 말.

더 깊게는 Latin `evanescere` = disappear, pass away와 연결됨. 이 말은 `e- / ex-` = out, away + `vanus` = empty, vain의 이미지.

따라서 `vanish`는 "비어 없어지다" → "사라지다, 자취를 감추다"의 뜻.

## 단어들

### vanish

- 발음: /ˈvænɪʃ/
- 구성: Old French `esvanir` < Latin `evanescere`
- 뜻: 사라지다, 자취를 감추다
- 어원적 연결: 있던 것이 비어 없어짐
- 사용 맥락: `vanish without a trace` = 흔적 없이 사라지다

### vanished

- 발음: /ˈvænɪʃt/
- 구성: `vanish` + `-ed`
- 뜻: 사라진, 자취를 감춘
- 어원적 연결: 있던 존재가 더 이상 보이지 않는 상태
- 사용 맥락: `a vanished civilization` = 사라진 문명

### vanishing

- 발음: /ˈvænɪʃɪŋ/
- 구성: `vanish` + `-ing`
- 뜻: 사라지는, 희미해지는
- 어원적 연결: 점점 비어 없어져 감
- 사용 맥락: `a vanishing species` = 사라져 가는 종

### evanescent

- 발음: /ˌɛvəˈnɛsənt/
- 구성: Latin `e-` = out, away + `vanescere` = disappear
- 뜻: 덧없는, 금방 사라지는
- 어원적 연결: 잠깐 나타났다 곧 비어 없어짐
- 사용 맥락: `evanescent beauty` = 덧없는 아름다움

### evanescence

- 발음: /ˌɛvəˈnɛsəns/
- 구성: `evanescent` 계열
- 뜻: 덧없음, 순간적으로 사라짐
- 어원적 연결: 오래 머물지 않고 사라지는 성질
- 사용 맥락: `the evanescence of youth` = 젊음의 덧없음

### vain

- 발음: /ˈveɪn/
- 구성: Old French `vain` < Latin `vanus`
- 뜻: 헛된, 소용없는; 허영심이 강한
- 어원적 연결: 내용이 비어 있어 실질이 없거나 자기 모습만 중시함
- 사용 맥락: `in vain` = 헛되이, `a vain attempt` = 헛된 시도

### vanity

- 발음: /ˈvænəti/
- 구성: Old French `vanite` < Latin `vanitas`
- 뜻: 허영, 헛됨
- 어원적 연결: 속이 비어 있는 자만이나 덧없는 가치
- 사용 맥락: `personal vanity` = 개인적 허영

## 기억 포인트

`van` 계열은 "비어 있어서 헛되거나 사라짐" 이미지.

- `vanish`: 비어 없어지듯 사라짐
- `evanescent`: 잠깐 있다가 사라지는
- `vain`: 속이 비어 헛됨
- `vanity`: 허영, 헛됨

## 비교 단어

### void

- 뜻: 비어 있음, 무효
- 구분 포인트: [[void]]는 빈 상태나 효력 없음이 중심. `van`은 "비어서 헛됨"과 "사라짐"까지 이어짐.

### vac

- 뜻: 비다, 비어 있다
- 구분 포인트: Latin `vacare` 계열은 빈자리·공석·비움의 실제 상태에 가까움. `van`은 더 추상적으로 헛됨, 덧없음에 자주 연결됨.

### vapor

- 뜻: 증기, 흩어짐
- 구분 포인트: [[vapor]]는 물리적으로 증발해 흩어지는 이미지. `vanish`는 원인과 방식보다 "보이지 않게 사라짐"이 핵심.

### vict

- 뜻: 이기다, 정복하다
- 구분 포인트: `vanquish`는 [[vict]]의 Latin `vincere` 계열. `vanish`와 어원적으로 관련 없음.
