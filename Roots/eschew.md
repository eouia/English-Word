# eschew

- 출발 단어: `eschew`
- 핵심 어원: Old French `eschiver` = avoid, shun
- 핵심 이미지: 의식적으로 피하고 멀리함
- 관련 문서: [[void]], [[evit]], [[vad]]
- 주의: 정확한 더 깊은 기원은 Germanic 계열로 보지만 형태 연결이 복잡함. 현대 학습에서는 "avoid deliberately" 이미지가 핵심.

## 출발 단어 분석

`eschew`는 Middle English `eschuen` / `eschewen`을 거쳐 들어온 말.

중간 형태는 Old French `eschiver` = avoid, shun. 더 깊게는 Frankish 또는 Germanic 계열의 "꺼리다, 피하다" 의미와 연결되는 것으로 설명됨.

따라서 `eschew`는 단순히 우연히 피하는 것이 아니라 "원칙이나 판단 때문에 일부러 멀리하다"의 느낌.

## 단어들

### eschew

- 발음: /ɪsˈtʃu/
- 구성: Old French `eschiver` = avoid, shun
- 뜻: 삼가다, 피하다, 의식적으로 멀리하다
- 어원적 연결: 꺼려서 가까이하지 않고 피함
- 사용 맥락: `eschew violence` = 폭력을 삼가다, `eschew luxury` = 사치를 멀리하다

### eschewed

- 발음: /ɪsˈtʃud/
- 구성: `eschew` + `-ed`
- 뜻: 피했다, 삼갔다
- 어원적 연결: 어떤 태도나 행동을 의식적으로 선택하지 않음
- 사용 맥락: `He eschewed publicity.` = 그는 세간의 주목을 피했다.

### eschewing

- 발음: /ɪsˈtʃuɪŋ/
- 구성: `eschew` + `-ing`
- 뜻: 피함, 삼가는 중
- 어원적 연결: 특정 방식이나 대상을 계속 멀리함
- 사용 맥락: `eschewing easy answers` = 쉬운 답을 피함

### eschewal

- 발음: /ɪsˈtʃuəl/
- 구성: `eschew` + `-al`
- 뜻: 회피, 삼감
- 어원적 연결: 어떤 것을 의식적으로 멀리하는 행위
- 사용 맥락: 드문 명사. 보통은 동사 `eschew`를 더 많이 씀.

## 기억 포인트

`eschew`는 "일부러 멀리하다" 이미지.

- `avoid`: 가장 일반적인 "피하다"
- `evade`: 빠져나가듯 교묘히 피하다
- `shun`: 사람이나 집단이 일부러 멀리하다
- `eschew`: 원칙·취향·판단 때문에 삼가다

## 비교 단어

### avoid

- 뜻: 피하다, 방지하다
- 구분 포인트: [[void]] 계열. 넓고 일반적인 말. `avoid mistakes`처럼 실수나 위험을 피할 때 자연스러움.

### evade

- 뜻: 회피하다, 빠져나가다
- 구분 포인트: [[vad]] 계열. 책임·질문·추적을 교묘히 빠져나가는 느낌.

### inevitable

- 뜻: 불가피한
- 구분 포인트: [[evit]] 계열. `evit`는 Latin `evitare` = avoid. `eschew`와 의미는 가깝지만 어원은 다름.

### shun

- 뜻: 피하다, 멀리하다
- 구분 포인트: 직접적인 사회적·감정적 회피에 자주 씀. `eschew`는 더 격식 있고 원칙적인 선택의 느낌.
