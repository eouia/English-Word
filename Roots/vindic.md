# vindic

- 출발 단어: `vindicate`
- 핵심 어원: Latin `vindicare` = claim, set free, avenge
- 핵심 이미지: 권리를 주장하거나 혐의를 벗겨 정당성을 세움
- 관련 문서: [[dict]], [[jud]], [[just]]

## 출발 단어 분석

`vindicate`는 Latin `vindicare`에서 온 말.

- `vindicare`: claim, set free, avenge
- 현대 의미: 의심이나 비난에서 벗어나게 하다, 옳았음을 입증하다

## 단어들

### vindicate

- 발음: /ˈvɪndəˌkeɪt/
- 구성: Latin `vindicare` = claim, set free, avenge
- 뜻: 정당성을 입증하다, 혐의를 벗기다
- 어원적 연결: 권리나 결백을 주장해 자유롭게 하거나 정당함을 밝힘
- 사용 맥락: `the evidence vindicated her` = 그 증거가 그녀의 결백을 입증했다

### vindication

- 발음: /ˌvɪndəˈkeɪʃən/
- 구성: `vindicate` + `-ion`
- 뜻: 정당성 입증, 혐의 벗김
- 어원적 연결: 비난이나 의심에서 벗어나 정당함이 드러남
- 사용 맥락: `a complete vindication of the policy` = 그 정책의 완전한 정당성 입증

### vindictive

- 발음: /vɪnˈdɪktɪv/
- 구성: Latin `vindicta` = revenge + `-ive`
- 뜻: 앙심 깊은, 보복하려는
- 어원적 연결: 권리 주장·복수 이미지가 개인적 보복 성향으로 굳어짐
- 사용 맥락: `a vindictive response` = 보복적인 반응

### vengeance

- 발음: /ˈvɛndʒəns/
- 구성: Old French `vengeance` ← Latin `vindicare`
- 뜻: 복수, 보복
- 어원적 연결: 잘못에 대해 응징하거나 갚으려 함
- 사용 맥락: `seek vengeance` = 복수를 추구하다

### avenge

- 발음: /əˈvɛndʒ/
- 구성: Old French `avengier` ← Latin `vindicare`
- 뜻: 복수하다, 원수를 갚다
- 어원적 연결: 잘못을 당한 사람이나 명예를 위해 응징함
- 사용 맥락: `avenge a defeat` = 패배의 원수를 갚다
- 주의: `avenge`는 보통 피해자나 잘못을 목적어로 둠. `avenge his brother`, `avenge an injustice`.

### revenge

- 발음: /rɪˈvɛndʒ/
- 구성: Old French `revengier` = take revenge
- 뜻: 복수하다; 복수
- 어원적 연결: 당한 해를 되갚는 행위
- 사용 맥락: `take revenge on someone` = 누군가에게 복수하다
- 주의: `revenge`는 개인적 감정의 보복 느낌이 강함. 명사로도 매우 흔함.

## 기억 포인트

`vindic` 계열은 "권리 주장, 결백 입증, 복수" 이미지.

- `vindicate`: 정당함을 입증함
- `vindication`: 입증되어 의심을 벗음
- `vindictive`: 보복하려는
- `vengeance`: 복수
- `avenge`: 남이나 명예를 위해 원수를 갚음
- `revenge`: 개인적 보복을 하거나 그 보복 자체

## 비교 단어

### justify

- 뜻: 정당화하다
- 구분 포인트: [[just]] 계열은 "법·정의에 맞음"에 초점. `vindicate`는 의심이나 비난을 벗겨 실제로 옳았음을 드러내는 느낌이 강함.
